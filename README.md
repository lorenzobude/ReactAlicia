# Licia Atzori — Personal Website

A personal website for **Licia Atzori**, showcasing her professional profile, holistic well-being services, and coaching activities.

🌐 **Live website:** [liciaatzori.netlify.app](https://liciaatzori.netlify.app/)

## About the Project

This project is a website designed to introduce Licia Atzori and present the services she offers to individuals and families seeking personal growth, emotional balance, and well-being.

## Tech Stack

The project is built using the following technologies:

- **[React](https://react.dev/)** — Component-based UI development.
- **[Gatsby](https://www.gatsbyjs.com/)** — Static site generation and website development.
- **[Sass](https://sass-lang.com/)** — CSS preprocessing and styling.
- **[React Helmet](https://github.com/nfl/react-helmet)** — Document head management.
- **[Netlify](https://www.netlify.com/)** — Website hosting and deployment.
